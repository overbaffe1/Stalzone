# SZMarket — STALCRAFT auction analytics (EAPI + craft/arbitrage)

Десктопный анализатор аукциона STALCRAFT (на русском): тянет цены из
официального EAPI, копит историю в SQLite, считает **что выгодно скрафтить**,
**что выгодно перепродать** и **какие лоты вот-вот кончатся** — всё с учётом
комиссии аукциона 5%.

- API: официальный STALCRAFT EAPI (`https://eapi.stalcraft.net`), secret-based auth
  (`Client-Id` + `Client-Secret`, без токенов).
- Предметы: [EXBO-Studio/stalzone-database](https://github.com/EXBO-Studio/stalzone-database)
  (2364 названия + иконки, `data/catalog.json`; чего нет у EXBO — в `data/overrides.json`).
- Рецепты: официальные `hideout_recipes.json` + `barter_recipes.json` EXBO
  (373 крафта + 2396 бартеров, `data/recipes.json`, обновляется `tools/build_data.py`).
- Только чтение: приложение никогда ничего не покупает/не выставляет.

## Быстрый старт (твой ПК, Windows)

```powershell
# 1. Клонируй репозиторий и перейди в него
git clone https://github.com/overbaffe1/Stalzone.git
cd Stalzone

# 2. Зависимости UI
pip install -r requirements-ui.txt

# 3. Креды: скопируй .env.example в .env и впиши свой Client Secret
copy .env.example .env
notepad .env

# 4. Запуск окна рядом с игрой
python -m ui.app
```

В окне: сверху регион (`RU/EU/NA/SEA` — **регион твоего персонажа**, не лаунчера!)
и список `itemId` через запятую → «🔄 Refresh prices» → «💰 Top deals» / «🧪 Top crafts».

Где брать `itemId`: поиск по названию в
[stalzone-database](https://github.com/EXBO-Studio/stalzone-database)
(`ru/items/.../*.json`, имя файла = ID). Примеры: `y1q9` — «Гадюка»,
`g4lk0` — военная аптечка, `96430` — аптечка индивидуальная.

## Тесты

```bash
pip install -r requirements.txt
python -m pytest tests/ -v
```

Unit-тесты — на фикстурах, без сети. Живые проверки EAPI гоняются в CI:

- `tools/smoke_eapi.py` — публичное демо-API (без секретов, всегда в CI);
- `tools/smoke_prod.py` — продакшн EAPI, только если заданы Secrets.
  Два формата на выбор (Settings → Secrets and variables → Actions →
  **Repository secrets**, либо Environment **`Stalzone_config`** — CI читает оба):
  либо три отдельных секрета `STALZONE_CLIENT_ID` / `STALZONE_CLIENT_SECRET` /
  `STALZONE_REGION` (имена `STALCRAFT_*` тоже подойдут), либо один многострочный
  секрет `STALZONE_CONFIG` со всеми тремя строками `KEY = VALUE` внутри.
  Без них — чистый SKIP.

## Структура

```
szmarket/        ядро (только stdlib: urllib + sqlite3)
  config.py      .env/ENV настройки, константы (комиссия 5%)
  eapi.py        EAPI-клиент: lots/history, пагинация, 429/retry, паузы
  store.py       SQLite: снапшоты лотов (SHA-дедуп) + история продаж (thread-safe)
  craft.py       экономика крафта/бартера: cost/revenue/profit/ROI (+ деньги)
  arbitrage.py   P25/median/P75, ликвидность, скоринг сделок
  snipe.py       лоты с истекающим сроком: потолок цены и профит
  catalog.py     каталог: имена, русский поиск, ручные подписи
  icons.py       ленивая подгрузка иконок EXBO с дисковым кэшем
ui/app.py        десктоп (CustomTkinter, русский, иконки)
data/
  catalog.json   2364 предмета: русские имена + иконки (из EXBO)
  recipes.json   373 крафта + 2396 бартеров (из EXBO)
  watchlist.json твой список отслеживания (правится из окна)
  overrides.json ручные названия для предметов вне базы EXBO
tools/
  build_data.py  пересборка catalog/recipes из свежих дампов EXBO
  smoke_eapi.py  живой smoke против демо-API (CI)
  smoke_prod.py  живой smoke против прод-API (CI, нужны Secrets)
tests/           pytest, без сети
agent_toolkit/   плейбук агента (GitHub Actions как вычислитель)
```

## Математика (коротко)

- Комиссия 5% с продажи → безубыток: `продажа = покупка / 0.95` (≈×1.0526).
- Крафт в плюс: `productCount × цена_продажи × 0.95 − Σ(ингредиенты) > 0`.
- Сделка: покупка лота + продажа по медиане истории даёт маржу ≥5%,
  при ликвидности (продаж/день) выше порога.

  (🟢 = всё загружено). Кнопки «скачать» больше нет.
- В списке предметов — галочки ✔: снять галочку = предмет пропускается при

  товара/входов, фильтр «Мин. продаж» (режет фейковые ROI с 1–2 продаж).
- Снайпер понимает торги: «🔥 ВЫКУПАЙ» или «✋ СТАВЬ максимум до X»
  (следующая ставка = текущая × 1.05, сортировка по времени конца).
- Кнопка «📋 Копировать» — результаты текстом в буфер обмена.
- Скорость: токен-бакет 100/мин + 4 потока (официальный лимит EXBO:
  100 токенов/мин на приложение, запрос аукциона = 2 токена).
- `tools/market_research.py` + workflow «Research»: живое исследование рынка
  по кнопке из GitHub Actions, отчёт — `fetched_info/research.md`.

## Что нового (v5 — реальная карта и умные цены)

- 🛰 Реальная карта Зоны: приложение скачивает рендеры STALZONE Wiki
  (север + юг) и показывает маршрут на них. Кнопка «🎯 Калибровка» —
  перетащи маркеры на истинные места один раз (сохраняется локально).
- Поселения перепривязаны к настоящим локациям (Заря — Институт,
  Рубеж — Барьер, Завет — Храмовая топь, Бар — Первомайский и т.д.).
- Тиры качества (qlt): лоты оцениваются по медиане своего тира,
  баффнутые вещи исключены из медиан. В строках — «тир 3 (редкое)».
- Цепочки крафта: входы считаются по min(рынок, скрафтить самому),
  в разбивке метка «⛓Верстак». Находит скрытый профит через полуфабрикаты.
- 🔁 Качели: обратимые обмены 1:1 (Уран↔Жнец, Масть↔Самсон и др.) —
  покупай дешёвую сторону, меняй, продавай дорогую.
- 🪞 Зеркало API: без ключа приложение работает через lunar-client.ru
  (данные могут отставать). С ключом — как раньше, официальный EAPI.
- Исследование: разделы «Качели» и «Когда продавать» (лучший час UTC).
